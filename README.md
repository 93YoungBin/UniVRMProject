# UniVRMProject

![GIF 2026-03-11 오전 10-19-21](https://github.com/user-attachments/assets/373b6e6a-29ac-43a7-bdc6-c3d9666a13f2)

### 개요

- 패러블 엔터테이먼트 기술 우대사항 경험 점검을 위한 셀프 프로젝트 제작
- 얼굴 인식으로 아바타의 표정을 변화시키며, 해당 데이터를 Photon Server를 이용하여 
타 클라이언트에서 동기화 하는 기능 개발
- 아바타 변경 시에도 동일하게 적용될 수 있는 구조 설계

### 개발 내용

- 웹캠 얼굴 인식 (MediaPipe Face Landmark)
- VRM 아바타 표정 제어
- Photon 기반 실시간 네트워크 동기화
